```text
WHERE A COST CANNOT BE ELIMINATED, DETERMINE LATER WHETHER IT CAN BE REDUCED
CURRENT VENDOR PRICING ≠ UNAVOIDABLE COST
```

## 1. Test

```text
FUNCTION REQUIRED
→ CURRENT PROVIDER / METHOD
→ CURRENT COST
→ ALTERNATIVE PROVIDERS / METHODS
→ SWITCHING CONSTRAINT
→ COMPETITIVE COST
→ RESIDUAL NECESSARY COST.
```

## 2. Firewalls

Do **not** assume current vendor pricing defines unavoidable cost.  
Do **not** select a vendor.  
Do **not** invent a savings estimate.  
Do **not** treat switching constraints as automatically permanent.

A residual necessary cost after competitive evidence may still classify as unavoidable, protected-transition, or controllable depending on WD-BILL-A-167. Classification remains **UNKNOWN** until evidence.
