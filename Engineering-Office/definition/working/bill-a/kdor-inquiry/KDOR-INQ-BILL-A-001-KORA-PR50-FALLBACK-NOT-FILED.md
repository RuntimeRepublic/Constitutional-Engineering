**Recommendation:** Begin as an **informal technical / legislative-research inquiry** using KDOR-INQ-BILL-A-001 (mail/phone to the published Office of Policy and Research address; optional copy to KLRD using published KLRD contacts).

That is the **least burdensome path** likely to answer whether aggregated transaction-band statistics exist. Kansas retailers generally report **period-aggregate taxable sales**, so a KORA filing will not magically create receipt-level bands if the Department does not maintain them.

## If a formal path becomes necessary

Use **PR-50 — Request for Copies or Access (General KDOR Records)** published at:

https://www.ksrevenue.gov/pdf/pr50.pdf

Mail (published on the form):

Kansas Department of Revenue  
Record Requests  
P.O. Box 3506  
Topeka, KS 66601-3506  

Attach KDOR-INQ-BILL-A-001 as the description of records sought (aggregates only).

## Do not use as the first form

**DO-41 — Request for Copies or Access (Kansas Tax Records)** is designed for copies of **filed tax returns/reports** and is **not** the correct first instrument for statistical aggregates. Using DO-41 would risk appearing to request confidential return copies, which this project has **not** authorized.

## KLRD assistance (optional parallel)

The Human Engineer may ask Kansas Legislative Research Department to assist as legislative research staff, using published KLRD contacts (785-296-3181; kslegres@klrd.ks.gov; Room 68-West, State Capitol). That is **not** a substitute KDOR email invented by this cycle.

## Legal note

This file does **not** invent a legal requirement to file KORA before an informal data inquiry. KDOR’s own PR-50 instructions state that written requests in other formats will not be denied, though additional information may be needed.

Human completes requester identity, signature, and any fee handling. This cycle does **not** sign or mail PR-50.
