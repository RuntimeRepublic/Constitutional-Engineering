## 1. NBBF candidate chain

```text
AVAILABLE LOTTERY GOVERNMENTAL REVENUE
→ ATTRIBUTION
→ AUTHORIZED PUBLIC FUNCTION
→ NBBF NODE
→ FOUR-MONTH ACCOUNTABILITY
→ PERFORMANCE SIGNAL
→ CONTINUED AUTHORITY / CORRECTIVE ACTION / LATER-DEFINED RESPONSE
```

Lottery-derived public money is intended to enter the same accountability architecture as other Bill A governmental resources. No operative enforcement procedure is created here.

## 2. Phase-One telemetry proving ground

```text
PAY → ATTRIBUTE → PARTITION → INVEST / HOLD → DISTRIBUTE → TRACK → NBBF → PERFORMANCE TELEMETRY
```

For identified purchases, candidate telemetry may include: purchaser; purchase; game; county of sale; county of domicile; government yield; Rule-of-72 partition; public-revenue attribution; taxpayer direction; NBBF node; performance.

Anonymous purchasing remains a **required design consideration**.
