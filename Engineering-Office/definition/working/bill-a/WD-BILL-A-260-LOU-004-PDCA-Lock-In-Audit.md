## Finding

Draft 1.11 already contains strong anti-perfection language: engineering targets are not certified results; planning ceilings are not final rates; TRR/ARR are not calculated; 90/10 feasibility is not certified; Human gates are not passed; unresolved matters remain visible.

It also contains language a reviewer could read as a **finished Future-State machine** with **named numbers** that look durable:

| Candidate lock-in | LOU locus | Risk |
|---|---|---|
| Layer 3 labeled **FUTURE → ARR** | §2.0.5 / §2.0.7 | Implies a single static end-state |
| GCD −0.25 percentage points / 3 months | §2.0.8 | Numerical formula recorded as Human Intent, not labeled planning-only |
| GCD 1% of original fixed-dollar / year | §2.0.8 | Same |
| Four-month NBBF accountability | §2.0.7 / §2.2 | Cadence recorded as Human Intent; mechanics not invented |
| Up to 5% state / 5% local | §2.0.3 | Explicitly planning ceilings — **low lock-in** if labels survive publication |
| 5-year / 7-year PT runway | §2.0.4 | Maximums; acceleration already allowed — residual lock-in if read as the only lawful periods |
| 4% post-prize Rule-of-72 | §2.0.11 | Labeled current planning, not enacted — residual lock-in if public readers treat it as the rule |
| 90/10 target | §2.0.11 | Engineering target + report-conflict rule — **low lock-in** |
| 50/50 geographic attribution | §2.0.11 | Human Intent numbers; 105-County formula unresolved |
| H.R. 25-style conversion of state legacy architecture | §2.0.2–§2.0.3 | Economic standard vs implementation mechanisms not fully split |
| Closed post-Bill-A compulsory KLRS | §2.0.3 | Durable authority boundary (likely CLASS I), not a rate |
| PT → zero statewide | §2.0.4 | Destination looks invariant; schedule looks parameter/transition |
| ALL-IN as primary path | §2.0.5 | Candidate, not accepted; not a numerical freeze |

Counterweights already in Draft 1.11:

- Q-BILL-A-001: **non-permanent assumptions about tax rates**; expiration/reauthorization; failure must produce signal and response (§2.2).
- Lowest sufficient authorized rate (§2.0.3).
- Current revenue ≠ required replacement; current spending ≠ TRR.
- Lottery: if 90/10 unachievable, **REPORT THE CONFLICT**; do not manipulate the denominator.
- Public review exists to expose better alternatives.

**Net:** Draft 1.11 does **not** expressly claim one bill produces a perfect tax system. It **does** leave “Future State” and several recorded numbers **ambiguous** as to whether they are durable guardrails or initial operating values.
