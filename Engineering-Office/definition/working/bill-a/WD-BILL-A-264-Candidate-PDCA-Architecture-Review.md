## Fit to existing Human Intent

| PDCA step | Existing support | Gap |
|---|---|---|
| PLAN | Signal-before-claim; bounded authority; baselines not equal to current collections; failure criteria implied by NBBF | Named PLAN artifacts / hypotheses not required LOU-wide |
| DO | Lottery proving ground; smallest bounded change is **not** a recorded Bill-A-wide rule | Statewide “smallest lawful change” not HI |
| CHECK | NBBF; four-month concept; telemetry tracks money; 90/10 conflict report | Measurement catalog not specified (correct: later SPEC) |
| ACT | Continued authority / corrective action / failure response / expiration or reauthorization (§2.2) | Retain/improve/accelerate/slow/modify/replace/suspend/retire ladder not named |
| REPEAT | Expiration/reauthorization; GCD path; non-permanent rate assumptions | No express continuous-improvement loop; “Future State” may imply stop |

## Lottery pattern as generalizable DO/CHECK

```text
BOUND THE EXPERIMENT → OPERATE → COLLECT TELEMETRY
→ COMPARE EXPECTED / ACTUAL → IDENTIFY VARIANCE
→ CORRECT → REPEAT → PROVE BEFORE EXPANDING.
```

This is a **useful candidate pattern**. The Lottery must **not** become controlling authority for unrelated mechanisms. Statewide expansion is **not** authorized by this CWC.

## Determination

PDCA as an **express Bill A operating architecture** = **HUMAN DECISION REQUIRED** (Q-BILL-A-016).

Pieces of PDCA are **SUPPORTED BY EXISTING HUMAN INTENT**. The named loop, Future-State meaning, and which numbers are parameters are **not**.
